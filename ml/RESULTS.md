- The learned model now handles **unseen verbs and phrasings** well ("nuke the

  Targets are now close (0.951 vs 0.927).
- Amount regression is still the weak part. Median error is about 1.0, but
  unseen bpm values pull the mean up.

The TF-IDF amount head is the weakest part. Bag-of-words does not represent
number magnitude, so unseen values regress toward the training mean. The
median absolute error is about 1.0, but the bpm outliers dominate the mean. Fix
directions: numeric token features, a dedicated number-extraction step, or a
transformer with digit-aware tokenization — and evaluate on more numeric rows.

## Error analysis (from `reports/errors_*_heldout.csv`)

1. **Unseen slang verbs are the biggest rule failure.** "nuke", "chuck", "lose",
   "erase", "no more" all fall through to no operation. The learned model gets
   some of these from context (`vocals`, `drums`) but not all.
2. **Cut vs trim is hard without a clear keep/delete cue.** "keep 0:10 through
   0:50" and "leave only 30 seconds starting at 1:00" confuse both models.
3. **Speaker canonicalisation is a rule win.** "I only need the host" means
   remove speaker 2. The learned model has seen "host" mapped to speaker 1 and
   gets the polarity wrong.
4. **Numbers do not transfer.** The TF-IDF regressor predicts the mean for
   unseen bpm values. This is a representation problem, not a tuning problem.
5. **Ambiguous instructions are labeled consistently but are genuinely hard.**
   "make the kick drum punchier by 3 db" is a gain because of the number, not an
   effect; the model sometimes picks `add_effect`.

The model is **not usable yet**: per-class thresholds tuned on the small
validation split make it over-predict operations, and bert-tiny is too small for
622 training rows. This is a pipeline check, not a result to present. The script
is ready for a real run:

```powershell
# Colab / Kaggle / friend's GPU
python scripts/train_transformer.py --model-name distilbert-base-uncased `
  --epochs 5 --lr 3e-5 --batch-size 16

# evaluate a checkpoint on either split
python scripts/evaluate.py --split test `
  --transformer-preds models/transformer/test_predictions.json
python scripts/evaluate.py --split heldout `
  --transformer-preds models/transformer/heldout_predictions.json
```

Before claiming transformer numbers: use DistilBERT (or a similar small
pretrained model), train on ≥1,000 hand-checked prompts, and tune thresholds on
validation only. The current tiny run does not meet that bar.
